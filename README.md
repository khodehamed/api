# تخمین قیمت سیم‌کارت ۰۹۱۲

قیمت خطوط ۰۹۱۲ از روی آگهی‌های قیمت‌دار [rond.ir](https://rond.ir) برآورد می‌شود. تشخیص رند جدا از قیمت است: اول کلاس خط (از جمله «معمولی») مشخص می‌شود، بعد قیمت از آگهی‌های هم‌کد و هم‌الگو به‌دست می‌آید.

نسخه‌های قبلی فقط چند پرچم دودویی (آینه‌ای، تعداد رقم یکتا، کد) داشتند و برای همین `0912201` را با `0912200` یکی می‌گرفتند، یا یک خط با دو صفر انتها را با خط معمولی میانگین می‌کردند. اینجا بلوک سه‌رقمی، صفرهای انتها، بلوک میانی و کلاس رند هر کدام در فاصلهٔ مقایسه وزن دارند و مدل تقویتی روی همین ویژگی‌ها آموزش می‌بیند.

## اجرا

```bash
pip install -r requirements.txt
uvicorn app.server:app --reload
```

سپس در مرورگر `http://127.0.0.1:8000` را باز کنید. خروجی JSON:

```bash
curl "http://127.0.0.1:8000/api/estimate?phone=09121796900&status=LIKE_NEW"
```

## داده و آموزش

آگهی‌ها در `data/market.db` و مدل در `data/model.joblib` ذخیره شده‌اند. روی سرور، `simprice-refresh.timer` هر روز ساعت ۰۳:۳۰ به وقت تهران کل آگهی‌های قیمت‌دار ۰۹۱۲ را دوباره می‌گیرد، مدل را می‌سازد و فقط اگر کاتالوگ کامل باشد جایگزین قبلی می‌کند. برای ساخت دوباره از صفحه‌های ذخیره‌شده در `/tmp/rond_pages/page_*.json`:

```bash
python scripts/train_market.py
python -m unittest tests.test_patterns tests.test_valuation
```

قیمت، قیمت درخواستی آگهی است نه قیمت قطعی معامله. خطای میانهٔ مدل روی بخشی از آگهی‌ها که در آموزش همان دور نبوده در پاسخ API می‌آید.
